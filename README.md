# DEMI — Decentralized Independent Music Icons

DEMI is an Android-first music creation and independent-artist community app.

## Product rules
- No cryptocurrency, meme coins, blockchain, tokens or wallets.
- Core app features are intended to be free.
- Artist/fan payments, if enabled, use ordinary payment providers and are separate from crypto.
- Users must have rights or permission for music they upload, split, cover or distribute.

## Android starter
- Native Android app using Kotlin and Jetpack Compose.
- Package: `com.demi.music`
- Minimum Android API: 26.
- Current starter includes a branded navigation shell, home screen and early studio interface.

## Planned milestones
1. Android foundation, branding and navigation.
2. Low-latency audio engine, microphone capture and multitrack recording.
3. Waveform editing, MIDI/instruments, effects, automation, mixing and export.
4. AI stem separation for vocals, drums, bass and other instruments.
5. Voice-cover workflow with alignment and rights safeguards.
6. Artist profiles, publishing, discovery, playlists, comments and analytics.
7. Digital fan gifts and conventional payment/payout integration, subject to provider approval and funding.
8. Build, test and package an Android APK.

## Important status
This repository contains a starter UI, not a completed DAW. Live recording, audio playback, stem separation, social services, payments and APK validation remain to be implemented and tested.

## Build
Open this repository as a project in Android Studio and allow Gradle sync to complete. Then run the app on an Android device or emulator.
